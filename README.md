# 3AM CLICKER

a minimal retro styled incremental clicker web game built with raw html css and javascript

## features

* custom click output counters with live cps calculations
* floating number particle animations on click and automated generation
* upgrade shop to boost manual click power purchase auto clickers and scale auto clicker multiplier
* scalable upgrade pricing logic with responsive UI status toggles

## project structure

```
.
├── index.html
├── script.js
├── style.css
└── imgs/
    └── 3am.png

```

## setup and installation

1 clone or download the repository files
2 place your custom click image at `imgs/3am.png`
3 open `index.html` in any modern web browser or serve via local server

## tech stack

* html5
* css3
* vanilla javascript es6
